# 🚀 FastAPI Practice & Learning Journey

این مخزن (Repository) شامل مجموعه‌ای از تمرین‌ها، پروژه‌های کوچک و تست‌های من در حین یادگیری فریم‌ورک **FastAPI** است. هدف از این پروژه، پیاده‌سازی مفاهیم پایه تا پیشرفته وب و بک‌اند با استفاده از پایتون است.

## 📌 موضوعات و قابلیت‌های پیاده‌سازی شده

در طول این تمرین‌ها، موارد زیر پیاده‌سازی و بررسی شده‌اند:

- **عملیات CRUD:** ایجاد، خواندن، به‌روزرسانی و حذف داده‌ها (Create, Read, Update, Delete).
- **احراز هویت و امنیت (Authentication):** 
  - پیاده‌سازی سیستم لاگین و ثبت‌نام.
  - استفاده از **JWT** (JSON Web Tokens) برای مدیریت نشست‌ها (Sessions).
  - **هش کردن پسوردها (Password Hashing)** با استفاده از الگوریتم‌های امن (مثل `bcrypt` یا `passlib`).
- **اتصال به دیتابیس (Database Integration):**
  - کار با **SQLAlchemy** به عنوان ORM (برای دیتابیس‌های PostgreSQL یا SQLite).
  - مدیریت مدل‌ها (Models) و اسکیماها (Schemas).
- **اعتبارسنجی داده‌ها (Data Validation):** استفاده از **Pydantic** برای تضمین صحت داده‌های ورودی و خروجی.

## 🛠️ تکنولوژی‌های استفاده شده

- **Python 3** (زبان اصلی)
- **FastAPI** (فریم‌ورک وب)
- **SQLAlchemy** (ORM دیتابیس)
- **Pydantic** (اعتبارسنجی داده‌ها)
- **Passlib / Bcrypt** (هش کردن پسوردها)
- **Python-JOSE** (مدیریت JWT)
- **SQLite** (دیتابیس لوکال برای تست)

## 📂 ساختار پروژه (مثال)

ساختار تمرین‌ها به صورت ماژولار و پوشه‌بندی شده است:

```text
fastapi-practice/
│

│   └── authentication.py   # بررسی لاگین بودن کاربر و دسترسی‌ها
│
├── db/                     # لایه دیتابیس و مدل‌ها
│   ├── database.py         # تنظیمات اتصال به دیتابیس (SQLAlchemy)
│   ├── db_article.py       # عملیات دیتابیس مربوط به مقالات
│   ├── db_user.py          # عملیات دیتابیس مربوط به کاربران
│   ├── hash.py             # توابع هش کردن پسوردها (Hashing)
│   └── models.py           # مدل‌های اصلی دیتابیس (Tables)
│
├── router/                 # مسیرها و Endpoint های API
│   ├── Article.py          # روت‌های مربوط به مدیریت مقالات
│   ├── blog_get.py         # روت‌های GET بلاگ
│   ├── blog_post.py        # روت‌های POST بلاگ

│   ├── product.py          # روت‌های مربوط به محصولات

├── exceptions.py           # مدیریت خطاهای سفارشی (Custom Errors)

## ⚙️ نحوه اجرا (Installation)

برای اجرای این پروژه روی سیستم خودتون، مراحل زیر رو دنبال کنید:

1. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/fastapi-practice.git
   cd fastapi-practice
   ```

2. **ساخت محیط مجازی (Virtual Environment):**
   ```bash
   python -m venv venv
   # در ویندوز:
   venv\Scripts\activate
   # در لینوکس/مک:
   source venv/bin/activate
   ```

3. **نصب پیش‌نیازها:**
   ```bash
   pip install -r requirements.txt
   ```

4. **اجرای سرور:**
   ```bash
   uvicorn app.main:app --reload
   ```

5. **مستندات API:**
   پس از اجرا، می‌توانید مستندات خودکار Swagger UI را در آدرس زیر مشاهده کنید:
   `http://127.0.0.1:8000/docs`
